## できること

**📱 スマホが PC の相棒に** — PC に出る QR コードをスマホで読むだけ。スマホで打った文字・指で描いた図・撮った写真・プリントのスキャンが、すぐ PC の文書に入ります。同じ Wi-Fi なら、インターネットがなくても使えます。

**📝 レポートの決まりごとを、自動で** — 目次・見出し番号・図表番号・相互参照・参考文献。数式・化学式・Mermaid の図。2段組み・縦書き・原稿用紙。PDF・Word にも書き出せます。

**📊 表の計算は Excel と同じ書き方で** — `=SUM(B2:B5)` などの約 200 の関数。表からグラフを作ると、表を直すたびにグラフも更新。

**🎤 スライドで発表、スマホがリモコンに** — テーマ・アニメーション・発表者ビュー。発表中はスマホが「次へ」のボタン・台本メモ・ペンになり、スマホのカメラを書画カメラとして映せます。PowerPoint・PDF・動画（MP4）に書き出し。
